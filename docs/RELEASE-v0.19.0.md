Primeira versão pública experimental, baseada no mod v19.

Baixe **NFSMW2012-RTX-v0.19.0.zip**, extraia tudo e execute **Instalar.cmd**. Instale antes o **ReShade 6.8.0 com full add-on support** para DirectX 10/11/12. Consulte o README para requisitos e tutorial completo. Os arquivos automáticos “Source code” não incluem os binários prontos.

- Reflexos, sombras/oclusão e iluminação complementar por DXR.
- Compactação adaptativa dos triângulos vazios, com os dados válidos preservados.
- Instalador com seleção do NFS13.exe, verificação de hashes, backup e restauração.
- Controle simples para ativar/desativar o addon e consultar o log.
- Horário e câmera livre opcionais; use as setas para olhar, pois o mouse tem um problema conhecido.
- Exemplo visual no README, com captura fornecida pelo autor.

Testado no Most Wanted 2012 v1.5.0.0, ReShade 6.8.0 e RTX 4060 em 1080p, offline. Desempenho varia por cena; **não há garantia de 60 FPS**. Existem limitações de reflexos, radiância oculta e máscara de HUD. Uso single-player/offline. A release não inclui o jogo nem a DLL/instalador ReShade.

Validação do pacote: compilação x86/x64/HLSL e testes de instalação/restauração em pasta simulada, inclusive após extrair o ZIP. Esses testes não certificam gráficos ou FPS em todos os computadores.
